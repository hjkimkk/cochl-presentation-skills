plugin cochl-design v2.0.0 auto-update

Install

Once per computer. Then restart Claude Code and type /cochl-design.

Everyone · one command

Install with auto-update on

Paste into the Terminal and press Enter. It adds the cochl marketplace, installs the plugin and turns auto-update on, so new versions arrive by themselves.

curl -fsSL https://raw.githubusercontent.com/hjkimkk/cochl-presentation-skills/main/scripts/migrate-to-plugin.sh | bash

Installed the old way before October 2026? The same command also removes the old git pull hook and moves the copied skills to a backup.

Prefer to type it yourself

Manual install

claude plugin marketplace add hjkimkk/cochl-presentation-skills
claude plugin install cochl-design@cochl --scope user

Then in Claude Code: /plugin → Marketplaces → cochl → Enable auto-update.

Help and contributing

Brand colors and fonts live only in skills/cochl-design/core/. CI blocks them anywhere else.

Something looks old

Restart Claude Code. Still old? Run the migration above, or claude plugin update cochl-design@cochl.

Only presenting a Cochl 101 deck? Duplicate the shared Figma file instead; no install needed.
