Mobile Dashboard Redesign2026-10-01

Principles

Insight 1

Ops managers are rarely at a desk; sound-event alerts must be reachable on a phone.

Insight 2

Navigation pattern (tabs vs drawer) shapes how quickly an alert can be found.

Insight 3

Alert density must stay scannable without hiding critical events.
