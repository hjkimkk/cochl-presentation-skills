Cochl Design Toolkit · Town hall
Explain · The skills inside

Six skills behind one command

Not sure which one? Type /cochl-design: it asks what you need and routes your request. Each skill also runs directly as /cochl-design:<name>, and the old command names still work.

cochl-presentation

Decks, brochures, banners

Investor, B2B, strategy, QBR and team decks; editable-SVG brochures, social banners and press kits.

pitch-deck

Official PT-template decks

Maps new content into the Cochl pitch deck style. Always outputs HTML and PPTX.

design-review

Design review decks

Proposal Review or Direction Alignment & Feedback meetings, from the two official templates.

proposal-doc

Design proposal documents

The structure, layout and writing style of the official Cochl proposals.

design-system

Build UI with @cochlearai/ui

Cochl tokens in React/Vite; a Figma node becomes the right component and props.

design-sync

Figma ↔ code drift

Does code match Figma? Drift and coverage reports, tracked on the dashboard.

Process · Before you start

First, open Claude Code

Do this once before the town hall. Claude Code needs a paid Claude plan: Pro, Max, Team or Enterprise.

1

Open the Terminal

Mac
Press ⌘ + Space, type Terminal, press Enter.
Windows
Open Start, type Terminal, press Enter.
2

Install Claude Code (once)

Mac
curl -fsSL https://claude.ai/install.sh | bash
Windows · PowerShell
irm https://claude.ai/install.ps1 | iex
Check it worked
claude --version
3

Start it and sign in

Start Claude Code
claude
The first time, a browser window opens: sign in with your Cochl account and come back to the Terminal.
How to run a command
Copy: select a grey box, press ⌘C (Ctrl+C)  →  Paste: click in the Terminal, press ⌘V (Windows: right-click)  →  Run: press Enter.
Next: one command in the Terminal; it turns on auto-update too. Afterwards, the desktop app's Code tab works too.
Cochl Design Toolkit · Town hall
Process · Install

Install: one command in the Terminal

Paste it into the Terminal and press Enter. It installs the plugin and turns on auto-update.

1Paste this, press Enter
curl -fsSL https://raw.githubusercontent.com/hjkimkk/cochl-presentation-skills/main/scripts/migrate-to-plugin.sh | bash
Adds the Cochl marketplace, installs cochl-design for your user in every folder, and turns on auto-update. Safe to run twice.
You should see (real output; usually under a minute)
3/3 Plugin ✔ Successfully added marketplace: cochl ✔ Successfully installed plugin: cochl-design@cochl (scope: user) set extraKnownMarketplaces.cochl.autoUpdate = true Done. Restart Claude Code, then type /cochl-design.
Desktop app · Settings → Plugins → Yours
Done when Cochl design shows under From marketplaces you added.

Something broke? Check here first

SymptomFix
/cochl-design not foundRestart Claude Code; claude plugin list should show cochl-design@cochl.
An old template shows upOld copies are still in ~/.claude/skills/: run the install command from slide 9 again; it moves them to a backup folder.
Install asks for a password or failsSet up git credentials: gh auth login, then gh auth setup-git.
Not on the latest version/plugin → Marketplaces → cochl → Update, then restart Claude Code.
